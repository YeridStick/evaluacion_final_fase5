Aplicación gráfica en Python para crear y visualizar un Árbol Binario de Búsqueda.

## Contraseña de ingreso

ARBOL

## Requisitos

Python 3 instalado.

La aplicación usa Tkinter, que normalmente viene incluido con Python.

## Ejecución

Desde la carpeta del proyecto, ejecutar:

```bash
python Fase4YeridRamirez.py
```

## Funcionalidades

- Ventana inicial con contraseña enmascarada.
- Agregar nodos enteros.
- Buscar nodos.
- Graficar árbol binario de búsqueda.
- Mostrar recorridos Preorden, Inorden y Posorden.
- Limpiar árbol.
- Salir de la aplicación.
- Validar datos no enteros.
- Validar máximo de 4 niveles.
